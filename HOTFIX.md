# Hotfix: история, старые тренировки, регистрация

Изменения не требуют миграций. База должна уже иметь v4.

- «История» → выбор дня → сразу последняя завершённая тренировка по дате
  начала с подходами. Промежуточного списка тренировок нет.
  Старые записи без снимка сохраняются. Для импортированной A/B/C они
  объединяются с соответствующими днями; одинаковые названия в других
  программах имеют отдельные группы и подписи программы.
- Незавершённая тренировка без снимка не блокирует редактор программ.
  «Тренировка» предлагает «Завершить с сохранением подходов» и затем
  открывает выбор программы/дня. Повторное или чужое нажатие не меняет данные.
- Активная тренировка со снимком по-прежнему защищена от конфликта с редактором.

## Amvera

По умолчанию регистрация закрыта: `OPEN_REGISTRATION=false`,
доступ определяется `ALLOWED_TELEGRAM_IDS`.

Для регистрации по ссылке задайте `OPEN_REGISTRATION=true` в переменных
приложения и перезапустите его. В этом режиме allowlist не ограничивает
личные чаты; группы остаются запрещены. Новому пользователю не копируется
A/B/C, история или программы другого пользователя. Уведомления работают
для зарегистрированных пользователей с собственными настройками.

Сохраните `GOOGLE_SHEETS_OWNER_TELEGRAM_ID=1853745926` и текущие секреты:
открытая регистрация не даёт другим пользователям экспорт в таблицу владельца.

Тесты запускаются только на временных базах через `unittest discover -s tests`.
Для публикации включайте в коммит только файлы этого hotfix; БД и резервные
копии не добавляйте. Не запускайте миграции повторно.
