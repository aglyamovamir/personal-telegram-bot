# Поиск упражнений в конструкторе

Сценарий: название программы → дни → поиск упражнения → карточка →
«Добавить в день». После добавления виден список дня и кнопка «Добавить ещё».
Настраивать подходы для создания программы не требуется.

Поиск использует существующие `exercises`, `exercise_muscles`, `exercise_images`.
SQL-записей и миграций нет. Поддерживаются русские/английские имена,
ё/е, регистр, части слов, словарь распространённых названий и небольшие опечатки.
Точные имена выше синонимов, затем начало названия, части слов и нечёткие совпадения.
Карточка позволяет проверить английское имя и оборудование: похожие упражнения
не подставляются автоматически. Русские названия из БД имеют приоритет;
если их нет, используются словарные подписи и английский fallback.

Карточка показывает основные мышцы и оборудование. Изображение отправляется
только по запросу. URL проверяется по формату; доступность доставки проверяет
Telegram при отправке. Для относительных путей проверяются наличие файла и
принадлежность существующей папке `data/repdb`. Ошибка доставки оставляет
текстовую карточку и черновик. Запрос и страница сохраняются при возврате.
Inline-навигация редактирует сообщение; при невозможности редактирования
отправляется новое. Изображения остаются отдельными сообщениями.

## Проверенный локальный экземпляр каталога

- Всего 602 упражнения; заполненный `name_ru` — 1.
- Непустой `image_url` — 467 упражнений.
- Связанные `exercise_images` — 601 упражнение.
- Хотя бы одна ссылка/путь — 601 упражнение; реально найден хотя бы один
  локальный файл для 601 упражнения. HTTP/HTTPS URL не обнаружены.
- Это данные локально предоставленной базы; состав серверного каталога
  отдельно не проверялся. Для картинок на сервере должны быть доступны файлы.

Ограничения: словарь не является полной профессиональной русской локализацией
602 названий; редкие варианты могут содержать английские слова. Нечёткий поиск
даёт подсказки, а не гарантию правильного упражнения. Доступность внешних URL
заранее не гарантируется. Черновики по-прежнему находятся в MemoryStorage и
не переживают перезапуск; снимки тренировок этой доработкой не меняются.
