Названия версий в руководствах миграций описывают шаги истории схемы.
Для текущего приложения требуется v4; миграторы не запускаются автоматически.
Последовательность для исходной старой БД: v1 → v2 → v3 → v4 → явный импорт A/B/C.
На готовой v4 не нужно повторно запускать старые миграторы.

## После очистки проекта

Документы перенесены из корня и `database/` в `docs/`; относительные ссылки
обновлены. Удалены неиспользуемые старые клавиатуры, демонстрационный скрипт
парсера и его отдельный неиспользуемый форматтер. Примеры парсера теперь
проверяются утверждениями в `tests/test_parser.py`, а не печатью в консоль.
Модули приложения и пути административных команд не перемещались.
